# Changelog

Packages follow semver. The registry version is exported separately as `REGISTRY_VERSION`.
A changed coefficient or a change in the set of formulas raises the minor version and is listed here with the reason and a link to the source.

## 1.0.0 — 2026-11-27

- First release: 26 formulas of the WIMSTA Formula Registry (registry 2026.11.27.1; categories body-fat, body-fat-ranges, bmi, waist-to-height, max-heart-rate, bmr, ideal-weight, bsa), 254 test vectors, JavaScript and Python packages.
